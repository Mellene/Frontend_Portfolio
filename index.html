About Me

저는 기획부터 배포까지 직접 끌고 가는 End-to-End 개발자입니다. State University of New York, Stony Brook에서 Computer Science(AI·데이터 사이언스 세부전공)를 전공했으며, 화면을 구현하는 데서 멈추지 않고 '이 기능이 왜 필요한가'를 먼저 정의한 뒤 개발합니다.

요구사항 정의 → UX 설계 → 개발 → 배포로 이어지는 전 과정을 혼자 완주한 서비스가 2건 있습니다. 사용자 인터뷰로 문제를 정의하고, Figma 프로토타입으로 해결안을 먼저 검증한 뒤, React·TypeScript로 구현하고 Supabase로 데이터 저장과 API 호출 구조를 구성합니다.

동시에 프로젝트를 굴러가게 만드는 역할도 해왔습니다. 7개국 연구자가 참여한 프로젝트의 PM으로 일정·이슈·리스크와 산출물을 관리했고, 프로젝트 동아리 회장으로 학기당 5~6개 팀의 진행을 책임졌습니다. 그리고 만든 것은 반드시 데이터로 확인합니다. 중고차 앱 개선안은 사용자 85%의 사용 의사로, 마약 예방 AR 캠페인은 5개국 6.8만 조회와 60% 이상의 인식 변화로 결과를 검증했습니다.
